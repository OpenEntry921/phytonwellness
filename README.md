# PHYTONWELLNESS Homepage

피톤웰니스 국문 브랜드 홈페이지이자 향후 글로벌 B2B 사업 플랫폼의 기반입니다. 국문 사이트는 지리산 편백 원료의 신뢰, 과정, 제품과 국내 판매 채널을 전달하고, 영문 사이트는 준비가 끝난 뒤 해외 바이어·유통 파트너를 위한 독립적인 전환 경로로 확장합니다.

## 기술 스택

- React + TypeScript + Vite
- 데이터 파일 기반 제품 관리
- 정적 HTML 메타데이터, sitemap, robots, JSON-LD
- Cloudtype 호환 정적 빌드 및 `/healthz`

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드 및 테스트

```bash
npm run build
npm test
```

`dist/`를 Cloudtype에서 정적 서비스하도록 구성할 수 있습니다. 실제 프로젝트/빌드 설정, 커스텀 도메인, 환경변수, DNS 연결 및 배포는 사용자 승인 뒤 수행합니다.
