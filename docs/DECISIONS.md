# 주요 의사결정 기록

기존 기록을 삭제하지 않고 변경 또는 폐기 결정을 새 항목으로 추가한다.

## 2026-10-08 — 국문 우선, 영문 비공개 기반

- **결정:** `/`에 국문 브랜드 페이지를 구축하고 `/en/`은 콘텐츠 준비 전 생성·색인하지 않는다.
- **이유:** 국내 신뢰 기반을 우선 완성하면서 영문 B2B를 단순 번역판으로 조기 공개하지 않기 위해서다.
- **대안:** 동시 공개, 언어 토글만 제공. 품질과 사실 검증 위험으로 보류했다.
- **장점/위험:** 집중도와 메시지 품질이 높지만 초기 해외 유입을 받지 못한다.
- **승인:** 사용자 지침으로 확정.

## 2026-10-08 — 정적·데이터 파일 기반 최소 구조

- **결정:** React/TypeScript/Vite와 정적 제품 데이터로 시작하고 DB, CMS, 결제를 도입하지 않는다.
- **이유:** 초기 운영 복잡성과 비용을 줄이고 Cloudtype 배포 및 확장을 가능하게 한다.
- **대안:** SSR 프레임워크/CMS. 콘텐츠 규모와 운영 요구가 확인될 때 재평가한다.
- **장점/위험:** 단순하고 이식 가능하나 비개발자의 즉시 편집과 기본 프리렌더링은 제한된다.
- **승인:** 사용자 지침에 따른 구현 결정; 최종 운영 승인 필요.

## 2026-10-08 — 미확인 콘텐츠의 명시적 보류

- **결정:** 실제 사진, 구매 링크, 제품 상세, 리뷰와 수출 조건을 만들지 않고 화면에 준비/확인 중으로 표시한다.
- **이유:** 허위 또는 과장 정보 공개를 방지한다.
- **대안:** 임시 스톡/예시 데이터. 브랜드 신뢰 위험으로 기각했다.
- **장점/위험:** 정직한 상태를 유지하지만 공개 전 교체 작업이 필수다.
- **승인:** 사용자 지침으로 확정.
