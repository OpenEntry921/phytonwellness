# 개발 로드맵

## Phase 1 — 국문 홈페이지 (진행 중)

**완료:** 전략 문서 체계, React/Vite 기반, 국문 원페이지 흐름, 제품 데이터 분리, 반응형 UI, 기본 메타/JSON-LD/sitemap/robots, 정적 health endpoint.

**완료 기준/남은 과제:** 기준 PPT·Word 대조, 실제 사진/제품 이미지, 모든 제품·사업자·연락처·구매 URL 검증, 접근성/브라우저 검수, 정적 사전 렌더링 결정, Cloudtype 스테이징 배포와 사용자 승인.

## Phase 2 — 영문 홈페이지 (계획)

영문 고유 콘텐츠와 `/en/`, 상호 hreflang, 제품 사양, 수출 프로세스, 검증된 카탈로그와 문의를 제공한다. 원어민/사업/규제 검수와 전환 테스트가 완료 기준이다.

## Phase 3 — 해외 B2B 기능 강화 (계획)

보안 문의 API, 샘플 요청, 문서 버전 관리, 국가별 유통 문의, 이벤트 측정을 구현한다. 개인정보·스팸·빈도 제한 검증과 운영 담당자의 처리 훈련까지 완료해야 한다.

## Phase 4 — 국가별 확장 (계획)

검증된 우선 국가별 시장 콘텐츠와 필요한 추가 언어를 도입하고 파트너 관리 프로세스를 정착시킨다. 현지 규제 검토, 책임자, KPI와 갱신 주기가 정의되어야 완료다.
