# 브랜드 전략

## 정체성과 핵심 문장

PHYTONWELLNESS는 편백 원료의 출발과 과정을 절제된 언어로 보여주는 자연주의 브랜드다. 국문 핵심 문장은 **“숲에서 시작합니다.”**, 영문 방향은 **“Forest, distilled.”**이다. 지리산, 사람의 손, 잎, 물과 증류, 제품, 집으로 이어지는 서사가 브랜드 경험의 중심이다.

## 원료와 공정 이야기

지리산 편백 원료, 채취, 증류는 핵심 이야기지만 세부 위치·권리·허가·장소·방식은 증빙 확인 후 공개한다. 현장 기록은 날짜와 출처를 관리하고 실제 촬영물만 사용한다. 현재 화면은 실제 사진이 필요한 영역을 명시한 플레이스홀더다.

## 디자인 철학

- 깊은 편백 녹색, 이끼·흙·물 계열의 저채도 팔레트
- 넓은 여백, 짧은 카피, 차분한 타이포그래피
- 숲의 깊이와 물의 투명함을 연상시키되 과도한 모션과 장식을 피한다.
- 모바일에서도 콘텐츠 순서와 읽기 리듬을 유지한다.

## 카피 원칙

국문은 담백하고 구체적으로 쓰며 원료와 제조사/제품의 관계를 명확히 한다. 영문은 직역보다 해외 바이어가 이해할 수 있는 자연스러운 B2B 언어를 쓴다. `Jirisan`, `Cypress`, `Steam Distillation`, `Forest Dew`, `Made in Korea`는 사실과 표기 근거 확인 후 사용한다.

## 금지 표현

의학적·살균·치료 등 확인되지 않은 효능, 미취득 인증, 불명확한 최상급, 허위 친환경 주장, 가짜 후기·거래 실적, 확인 전 원산지와 수출 실적을 쓰지 않는다. AI 생성 현장 이미지를 실제 사진처럼 사용하지 않는다.
