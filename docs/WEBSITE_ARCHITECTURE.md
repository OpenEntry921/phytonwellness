# 웹사이트 기술 설계

## 현재 구조

- Vite + React + TypeScript 단일 페이지 브랜드 사이트
- `src/main.tsx`: 의미론적 섹션과 화면 조합
- `src/data/products.ts`: 제품별 이름, 설명, 용도/성분/신고번호/구매 링크를 위한 데이터 모델
- `src/styles.css`: 반응형 디자인 시스템
- `public/`: robots, sitemap, health check

본문은 클라이언트 오류 전에도 메타 정보를 제공하며, 다음 단계에서 정적 사전 렌더링을 적용해 검색 봇이 모든 본문을 안정적으로 읽도록 검증한다.

## 언어와 라우팅

한국어는 `/`, 영어는 `/en/`을 사용한다. 언어별 콘텐츠 객체/파일을 분리하며 문장 키를 기계 번역으로 공유하지 않는다. 영문 준비 전 `/en/`은 생성하지 않고 robots/sitemap에서도 제외한다. 공개 시 언어별 canonical과 상호 `hreflang`을 추가한다.

## 제품 데이터

현재 정적 TypeScript 데이터로 관리한다. 향후 검증 상태, 이미지 출처, 규격, 문서 버전, 국가별 제공 가능 여부를 스키마에 추가할 수 있다. 빈 값은 추측해 채우지 않고 UI에 ‘확인 중’으로 표현한다.

## 문의/API 확장

초기에는 검증이 필요한 메일 링크만 표시한다. 향후 Cloudtype 서버 API가 폼 검증, 동의 기록, honeypot/CAPTCHA, IP 기반 빈도 제한, 오류 코드, 메일플러그 지원 방식 전송을 담당한다. 클라이언트에는 SMTP 비밀정보를 두지 않으며 개인정보를 애플리케이션 로그에 남기지 않는다.

## 확장 원칙

콘텐츠 규모와 운영 인력이 필요성을 입증하기 전 DB/CMS/회원/결제를 추가하지 않는다. 분석 이벤트는 명명 규칙을 정한 뒤 동의 정책과 함께 도입한다.

## 상단 로고 및 고정 내비게이션

- 헤더는 기존 본문 위 배치를 유지하면서 `position: fixed; top: 0; z-index: 10`으로 스크롤 중에도 표시한다. 기존 배경과 PC 82px / 모바일 68px 높이를 유지한다.
- 상단 홈 링크는 `/images/jirisan-hinoki/Phytonwellness_Monogram_Logo.png` 원본을 사용한다. 투명 배경과 비율을 보존하고, 이미지 높이는 PC 70px / 모바일 56px로 표시한다. 대체 텍스트는 `PHYTONWELLNESS`, 링크는 `#top`이다.
- 본문 및 섹션 앵커에는 헤더 높이 + 16px의 `scroll-margin-top`을 적용한다. `#top`은 여백 없이 페이지 최상단으로 이동한다.
- 기존 모바일 동작(760px 이하 주요 메뉴 숨김, 구매처 링크 표시)을 유지한다. 현재 모바일 메뉴 열기·닫기 버튼은 없다.

검증: Chromium에서 1440, 1024, 768, 760, 390, 320px 너비로 로고 로딩·비율·헤더 내부 배치·메뉴 겹침 여부, 페이지 중간/하단 헤더 고정, 표시된 메뉴의 섹션 이동 및 로고의 최상단 이동을 확인했다. `npm run build` 통과. `npm test`는 저장소에 테스트 파일이 없어 종료 코드 1을 반환했다. 이미지 원본과 기존 사진 배치는 변경하지 않았다.
