# 프로젝트 전략

## 배경과 목적

PHYTONWELLNESS 홈페이지는 일반 쇼핑몰이 아니라 한국의 편백 원료와 제품을 신뢰할 수 있게 소개하고 국내 판매와 글로벌 B2B 사업을 연결하는 장기 디지털 거점이다. GitHub는 코드와 사업 전략을 함께 보존하는 단일 기록 저장소다.

## 확정 전략

- **국내 사업:** 원료의 출처, 직접 채취·증류 과정, 브랜드 원칙을 중심으로 인지와 신뢰를 만들고 확인된 외부 판매 채널과 기업·대량 구매 상담을 연결한다.
- **해외 사업:** 영문 사이트를 번역본이 아닌 바이어 발굴, 유통 파트너십, 수출 상담을 위한 독립 플랫폼으로 단계적으로 발전시킨다.
- **역할 분리:** 국문 사이트는 국내 신뢰와 판매를, 영문 사이트는 해외 바이어와 수출 확대를 지원한다.
- **인프라:** Cloudtype은 웹 호스팅과 필요한 서버 API, Cloudflare Free는 DNS·CDN·보안, 메일플러그는 이메일을 담당한다.
- **운영:** 중요한 변경은 전략 문서와 함께 PR로 검토하고 사용자 승인 후 반영한다.

## 단계별 전략

1. 국문 브랜드 페이지, 제품/구매 연결, SEO와 배포 기반을 완성한다.
2. 영문 고유 콘텐츠, 제품 규격, 수출 문의와 카탈로그 경로를 구축한다.
3. 샘플 요청과 수출 자료·국가별 유통 문의 및 측정을 강화한다.
4. 검증된 시장별 콘텐츠, 언어 및 파트너 관리 체계를 확장한다.

## 홈페이지의 역할

`숲 → 사람 → 잎 → 물 → 제품 → 집 → 신뢰 → 구매`의 흐름으로 브랜드 근거를 설명한다. 제품 정보는 외부 구매를 돕고, 파트너 영역은 국내 대량 구매와 장기 해외 전환을 담당한다. 자체 결제·회원·불필요한 CMS는 도입하지 않는다.

## 성과 측정 기준

방문자, 언어별 방문, 제품 관심, 구매처 클릭, 해외 국가별 방문, B2B 문의, 샘플 요청, 카탈로그 다운로드를 단계에 맞게 측정한다. 도구 도입 전 개인정보/동의와 운영 필요성을 검토하며 검색 순위나 AI 추천은 보장하지 않는다.

## 검토 중인 가정

원료 채취지와 허가, 직접 채취/증류의 구체 사실, 제조 장소, 제품 상세와 신고번호, 법인/연락처, 공식 구매 URL, 해외 인증 및 수출 가능 국가가 미확인이다. 기준 PPT·Word 원본도 저장소에서 확인되지 않았다. 이 항목은 검증 전 확정 카피로 사용하지 않는다.
